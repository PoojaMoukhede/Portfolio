# Pooja Moukhede - Portfolio (Next.js & Tailwind CSS)

A modern, minimal, high-performance portfolio built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS (v3)**, **Framer Motion**, and **Lucide React**.

## Features

- **Light & Dark Theme**: Seamless theme switching with `next-themes` and persisted preference without flash of wrong theme.
- **Dynamic Age Calculation**: Computed automatically based on DOB (29 June 1998) updating dynamically every year.
- **Categorized Technical Arsenal**: Frontend & Languages, Backend & Real-Time, Video & Media APIs, Databases & Tools.
- **Interactive Experience & Education Timelines**: Showcasing full project details, technologies, and achievements.
- **Filterable Projects Grid**: Category tabs (All, Full Stack, Real-time, Frontend) with live preview and repository links.
- **Working Contact Form**: Integrated with Getform endpoint and direct contact channels.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewports with glassmorphism and subtle micro-animations.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
npm run build
npm run start
```
